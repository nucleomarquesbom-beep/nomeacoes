# Gerador de Nomeações — fase de exemplos

Esta versão usa o PDF real `NI 162 RET.pdf` como exemplo e já separa os jogos.

Com a lista `Nuno Guerra` + `Gonçalo Rosa`, o resultado esperado inclui:
- LUSITANO DE ÉVORA C. - ATLÉTICO CP SAD — ambos encontrados; Gonçalo Rosa é 1.º árbitro e Nuno Guerra é 4.º árbitro.
- ACADÉMICA COIMBRA/OAF SDUQ - VARZIM SC SDUQ — apenas Gonçalo Rosa encontrado; é 4.º árbitro e o modelo escolhido é o de 1 elemento.

As regras são baseadas na estrutura observada no PDF da FPF. O PDF mostra a competição, depois cada jogo com o primeiro árbitro na mesma linha do jogo e os restantes árbitros nas linhas seguintes; as associações aparecem à direita. Os blocos também podem conter VAR/AVAR e OBSV, que não são tratados como árbitros principais.
