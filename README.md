# Gerador de Nomeações — NAF Marques Bom

Primeira versão da aplicação web.

## Objetivo
- Carregar PDF da FPF
- Identificar árbitros da lista
- Distinguir Futebol/Futsal/Observadores
- Escolher automaticamente o modelo
- Procurar fotografias
- Gerar JPG
- Criar nomeações manualmente

## Desenvolvimento
```bash
npm install
npm run dev
```
